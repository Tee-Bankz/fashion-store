# Lumina Collectives Fashion Store Website

**Course:** CSC 106 / IFT 203 – Introduction to Web Technologies  
**Project:** Lumina Collectives

## Project Overview

A fully functional multi-page website for a fashion house that showcases products, displays team information, and enables users to make inquiries and book appointments.

**Live Site:** [Lumina Collectives](https://lumina-collectives.vercel.app/index.html)

**GitHub Repository Link:** [GitHub Link](https://github.com/Tee-Bankz/fashion-store.git)

## Website Features

- **Product Showcase** – Fashion items displayed with images and descriptions
- **Consistent Navigation** – Uniform link structure across all pages
- **Board of Trustees** – Team members' photos and information
- **Inquiries & Appointments** – User form for inquiries and appointment bookings
- **Upcoming Events** – Fashion shows and promotional events
- **Marquee Feature** – Scrolling announcements on all pages
- **Interactive Elements** – Form validation and dynamic updates with JavaScript
- **Responsive Design** – Consistent styling with external CSS
- **Clean DOM Structure** – Organized HTML structure

## Pages Included

- Home (`index.html`)
- Products (`products.html`)
- Board of Trustees (`trustees.html`)
- Contact & Appointments (`contact.html`)
- Upcoming Events (`events.html`)
